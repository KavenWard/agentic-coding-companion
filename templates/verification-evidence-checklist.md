# Verification Evidence Checklist

- [ ] The requested behavior is reproduced or demonstrated.
- [ ] Relevant tests pass.
- [ ] The diff is limited to the intended scope.
- [ ] Error paths and boundary cases were checked.
- [ ] No secrets or sensitive data were added.
- [ ] Dependencies and configuration changes are explained.
- [ ] Remaining uncertainty is stated plainly.
- [ ] A human owner has reviewed the result.
