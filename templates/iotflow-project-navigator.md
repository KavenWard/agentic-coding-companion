# IoTFlow Project Navigator

IoTFlow is the book's fictional cross-protocol IoT platform. It provides a stable setting for practicing delegation, context management, verification, and governance.

## Use it as a practice loop

1. Pick a bounded change: a protocol adapter, telemetry path, configuration migration, or test.
2. Write a Mission Brief.
3. Give the agent only the relevant architecture and naming context.
4. Require a diff, tests, and verification evidence.
5. Review local correctness against system-level intent.

## Suggested exercises

- Add a device capability while preserving protocol boundaries.
- Trace a telemetry defect from input to persisted output.
- Migrate a configuration schema with backward compatibility.
- Review an agent-generated change for hidden assumptions.
