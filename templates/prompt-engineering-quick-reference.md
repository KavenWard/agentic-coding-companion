# Prompt Engineering Quick Reference

## State the outcome

Describe the user-visible result and how success will be checked.

## Bound the task

Name the files, interfaces, constraints, and explicit exclusions.

## Supply context deliberately

Include the smallest complete set of project facts. Link to source files instead of pasting unrelated material.

## Ask for a plan before execution

For risky or multi-step work, require a short plan and identify the first verification point.

## Require evidence

Ask for commands run, tests passed, files changed, and unresolved uncertainty.

## Separate authority from intent

State which tools and actions are allowed. Do not treat a model's confidence as proof.
