# Agentic Coding Companion

Practical resources for **[Agentic Coding: Building Reliable Software with AI Agents](https://agenticcoding.pages.dev/)** by Kaven Ward.

> AI can write code quickly. Reliable software still depends on intent, context, verification, and human accountability.

## What this repository contains

- [Chapter guide](chapters/README.md): a short map of the book's 24 chapters and appendices
- [Engineering templates](templates/): reusable artifacts for agent-assisted development
- [Prompt reference](templates/prompt-engineering-quick-reference.md): patterns for clear, testable requests
- [IoTFlow navigator](templates/iotflow-project-navigator.md): the book's running example project

## Start here

1. Write a **Mission Brief** before delegating a task.
2. Give the agent the smallest complete context it needs.
3. State tools and permissions explicitly.
4. Require evidence: tests, checks, diffs, and remaining uncertainty.
5. Review the result against the system's global intent.

## About the book

Agentic Coding examines the move from autocomplete and chat assistants to tool-using, multi-step coding agents. It focuses on the durable engineering questions behind fast-changing tools: what agents can do, where they fail, how to verify their output, and how teams can organize work around reliable collaboration.
